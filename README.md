# MemCalib: Benchmarking and Optimizing Memory Use in LLM Agents

[Project Page](https://quark-medical.github.io/MemCalib-Project/) · [Paper](https://arxiv.org/abs/2609.24259) · [Code](https://github.com/Quark-Medical/memcalib) · [Dataset](https://huggingface.co/datasets/ZiLaotou/MemCalib)

This repository hosts the MemCalib project website.

**MemCalib** is a benchmark for evaluating whether LLM agents give each memory an appropriate degree of influence over their responses. **MemCalib-RL** uses ordered bidirectional counterfactual credit assignment to improve memory use by separating over-use and under-use signals.
